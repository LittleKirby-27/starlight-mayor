# 3–5 人试玩测试方案

## 每位试玩者任务

1. 不看攻略进入第一关，记录是否在 5 分钟内理解建造、政策和四项指标。
2. 至少完成一关；若失败，记录失败原因和当时剩余资源。
3. 观察紧急事件是否给了足够阅读与决策时间。
4. 试听通关、失败和成就音效，评价音量和风格是否统一。
5. 分别评价 3D 建筑辨识度、画面流畅度和手机操作体验。
6. 使用游戏右下角反馈按钮提交意见。

## 建议记录字段

| 字段 | 示例 |
|---|---|
| 设备 | Windows 笔记本 / iPhone / Android |
| 完成关卡 | 第 1 关 |
| 用时 | 4 分 10 秒 |
| 是否遇到 bug | 否 / 说明现象 |
| 最难理解的地方 | 政策效果 |
| 3D 辨识度（1–5） | 4 |
| 流畅度（1–5） | 5 |
| 音效统一性（1–5） | 4 |
| 最希望修改的一点 | 自由填写 |

## 迭代优先级

- P0：无法开始、无法通关、无法进入下一关、页面崩溃。
- P1：目标说明不清、时间明显不合理、移动端无法操作、严重卡顿。
- P2：模型细节、动画、音量、文案与小范围布局问题。

先解决所有 P0，再处理影响多数人的 P1；P2 按出现频率和制作成本排序。
