# 需求文档

## 1. 应用概述

### 1.1 应用名称
《星光市长:重建夜空》

### 1.2 应用描述
一款3D城市建设+市长决策模拟+环保教育闯关游戏。玩家扮演现代城市新任市长,在保证经济发展的同时,通过合理规划城市建设和环保政策,逐步恢复夜空中的星星,让城市重新变成宜居、可持续发展的绿色城市。使用Three.js实现3D效果,使用MiniMax M3多模态大模型实现AI市长助手功能。

### 1.3 目标用户
14-25岁中国城市年轻人

### 1.4 游戏背景
玩家扮演一座现代城市的新任市长。随着城市快速发展,出现了光污染、空气污染、绿地减少、能源浪费等问题。城市居民越来越难看到星空。玩家需要在保证经济发展的同时,通过合理规划城市建设和环保政策,逐步恢复夜空中的星星,让城市重新变成宜居、可持续发展的绿色城市。

### 1.5 视觉风格
- 3D俯视角城市
- 类似城市天际线(Cities: Skylines)的布局方式
- 卡通写实风格
- 昼夜循环系统
- 夜晚可以看到城市灯光
- 环境变化实时可视化
- 地面采用优化渲染技术,消除闪烁问题
- 河道呈现动态水流效果,包含增强的反射、透明度与宽度表现
- 动态星斗与银河夜空重新设计,星光效果更加自然流畅
- 山丘具备细节层次,包含岩石纹理、植被差异、雾气萦绕等效果

### 1.6 单局时长
单关约5分钟，六关逐步提高压力

## 3. 业务规则与逻辑

### 3.1 关卡模式

游戏共六个关卡,依次为:
1. 第一关:建设新城区(目标:建设5座住宅区、3座商业区、3座公园,星空指数达到22%,时间限制:4分30秒)
2. 第二关:解决光污染(目标:推广LED路灯、控制夜间照明,环境指数达到60、星空指数达到45%,时间限制:4分45秒)
3. 第三关:控制工业排放(目标:限制工业排放、建设3座风力发电机,环境指数达到70、星空指数达到65%,时间限制:5分钟)
4. 第四关:推广绿色交通(目标:建设3座地铁站、鼓励绿色出行,环境指数达到75、星空指数达到85%,时间限制:5分15秒)
5. 第五关:实现低碳城市(目标:建设5座太阳能电站、实施垃圾分类和碳预算,环境指数达到85、居民满意度达到75、星空指数达到95%,时间限制:5分30秒)
6. 最终关:恢复银河级夜空(目标:财政达到1200、环境与满意度达到85、星空指数达到100%,时间限制:6分钟)

关卡按顺序解锁,完成前一关卡后解锁下一关卡

### 3.2 四大指标系统

#### 3.2.1 财政收入
- 初始值:1000
- 来源:商业区、工业区每回合产生收入
- 消耗:建设建筑、实施政策、维护建筑
- 财政收入为0时无法建设新建筑和实施政策
- 财政收入归零时触发失败

#### 3.2.2 环境指数
- 初始值:50
- 范围:0-100
- 影响因素:工业区降低、公园提升、政策影响
- 归零时触发失败

#### 3.2.3 星空指数
- 初始值:10
- 范围:0-100
- 影响因素:工业区降低、风力发电机提升、太阳能电站提升、政策影响
- 达到100时完成最终关卡目标

#### 3.2.4 居民满意度
- 初始值:60
- 范围:0-100
- 影响因素:住宅区、公园、学校、地铁站提升,工业区降低
- 归零时触发失败

### 3.3 星空恢复系统

根据星空指数变化,夜空视觉效果分为五个阶段:
- 0-20%:几乎看不到星星,夜空灰暗
- 21-40%:少量星星出现
- 41-60%:银河轮廓显现
- 61-80%:满天繁星
- 81-100%:完整银河夜空

夜空呈现动态星光效果,星星闪烁自然流畅,动态星斗与银河夜空重新设计,视觉效果更加真实

### 3.4 昼夜循环系统

游戏内时间以回合制推进,每回合代表一天,时间流速大幅降低,使变化过程更舒缓:
- 白天:显示城市建筑、道路、绿化
- 夜晚:显示城市灯光、星空效果
- 每回合自动切换昼夜
- 每回合持续时间延长,玩家有充足时间观察城市变化和思考决策
- 昼夜过渡采用平滑插值算法,精确模拟黎明、正午、黄昏、深夜四个时段的光照色温与强度渐变,保持视觉连续性

### 3.5 随机事件触发规则

- 在任何连续的7天(游戏内时间)周期内,最多触发2次随机事件
- 事件类型根据当前关卡和城市状态动态生成
- 玩家必须在30秒内做出选择,否则自动选择默认选项

### 3.6 紧急事件触发规则

- 紧急事件随机触发,不受随机事件触发规则限制
- 触发频率略微加快,增加决策压力
- 触发紧急事件时,游戏暂停,玩家必须选择一项紧急政策应对
- 玩家必须在60秒内做出选择,否则自动选择默认选项

### 3.7 AI市长助手规则

- 使用MiniMax M3多模态大模型实现
- 玩家可随时唤起对话框
- AI助手根据当前城市状态、四大指标、关卡目标提供决策建议
- AI助手不直接告知最优解,而是提供2-3种可行方案供玩家选择

### 3.8 初始地图设计

每个关卡提供精心设计的初始地图,包含:
- 基础地形:山丘、河流、湖泊等自然地貌
- 完整道路网络:主干道、次干道、支路
- 初始建筑群落:若干住宅区、商业区、公园、学校等基础设施
- 玩家在此基础上继续建设和优化城市

### 3.9 关卡时间限制机制

#### 3.9.1 时间上限设置
每个关卡采用约5分钟的高压时间上限,随关卡难度递增:
- 第一关:4分30秒
- 第二关:4分45秒
- 第三关:5分钟
- 第四关:5分15秒
- 第五关:5分30秒
- 最终关:6分钟

#### 3.9.2 时间压力视觉反馈
- 剩余时间充足时,时间显示为白色
- 剩余时间少于总时长的一半时,时间显示为黄色
- 剩余时间少于2分钟时,时间显示为红色并闪烁
- 剩余时间少于1分钟时,屏幕边缘出现红色警告框

#### 3.9.3 超时处理规则
- 超出时间限制时,游戏立即结束
- 判定为失败,进入失败结算页面
- 失败结算页面显示「超出时间限制」

#### 3.9.4 时间剩余提示
- 顶部信息栏实时显示剩余时间
- 剩余时间以分钟和秒为单位显示,例如「04:30」

### 3.10 失败判定规则

#### 3.10.1 失败条件
满足以下任一条件时判定失败:
- 财政收入归零
- 环境指数归零
- 居民满意度归零
- 超出关卡时间限制

#### 3.10.2 失败提示
失败时立即进入失败结算页面,显示具体失败原因:
- 「财政收入归零」
- 「环境指数归零」
- 「居民满意度归零」
- 「超出时间限制」

### 3.11 全局成就系统

#### 3.11.1 成就分类
成就按类型分为五大类:
- 建设类:与城市建设相关的成就
- 政策类:与政策实施相关的成就
- 环保类:与环境保护相关的成就
- 经济类:与财政管理相关的成就
- 综合类:跨多个维度的综合成就

#### 3.11.2 成就解锁条件与奖励

**建设类成就**:
- 「初级建设者」:建设10座建筑,奖励:初始财政+100
- 「中级建设者」:建设30座建筑,奖励:初始财政+200
- 「高级建设者」:建设50座建筑,奖励:初始财政+300
- 「绿色城市规划师」:建设10座公园,奖励:环境指数初始值+5
- 「清洁能源先锋」:建设10座风力发电机或太阳能电站,奖励:星空指数初始值+5

**政策类成就**:
- 「政策实践者」:实施20项政策,奖励:政策成本降低5%
- 「政策专家」:实施50项政策,奖励:政策成本降低10%
- 「环保倡导者」:实施10项环保主题政策,奖励:环保政策效果提升10%

**环保类成就**:
- 「星空守护者」:星空指数达到100%,奖励:解锁特殊建筑「天文台」
- 「环境卫士」:环境指数保持在80以上持续10回合,奖励:环境指数衰减速度降低10%
- 「碳中和先锋」:完成第五关,奖励:初始财政+500

**经济类成就**:
- 「理财高手」:财政收入达到5000,奖励:商业区收入提升5%
- 「经济奇才」:财政收入达到10000,奖励:商业区收入提升10%
- 「节约模范」:单局游戏中财政支出低于3000,奖励:建筑成本降低5%

**综合类成就**:
- 「完美市长」:四大指标同时保持在90以上,奖励:解锁特殊称号「完美市长」
- 「速通大师」:在10分钟内完成任意关卡,奖励:时间限制延长10%
- 「全关卡通关」:完成所有六个关卡,奖励:解锁自由模式

#### 3.11.3 成就展示与追踪
- 成就系统界面展示所有成就,包括已解锁和未解锁的成就
- 每个成就显示名称、图标、描述、解锁条件、完成进度、奖励内容
- 已解锁成就图标为彩色,未解锁成就图标为灰色
- 成就进度实时更新,例如「建设10座公园(5/10)」

#### 3.11.4 成就徽章与进度提示
- 玩家达成成就条件时,屏幕中央弹出成就解锁提示
- 成就解锁提示显示成就名称、成就图标、成就描述、奖励内容
- 成就徽章在成就系统界面中永久保存
- 游戏过程中,左下角显示当前接近完成的成就进度提示

所有建筑的正面效果数值中幅下调:

## 4. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 财政收入不足 | 无法建设新建筑和实施政策,提示「财政不足」 |
| 财政收入归零 | 触发失败,显示「财政收入归零」 |
| 环境指数归零 | 触发失败,显示「环境指数归零」 |
| 居民满意度归零 | 触发失败,显示「居民满意度归零」 |
| 超出时间限制 | 触发失败,显示「超出时间限制」 |
| 地图空间不足 | 提示「无可用空间」,无法放置建筑 |
| 建筑放置位置不合法 | 提示「无法在此位置建设」 |
| 随机事件超时未选择 | 自动选择默认选项 |
| 紧急事件超时未选择 | 自动选择默认选项 |
| AI助手无法理解玩家提问 | 回复「抱歉,我没有理解您的问题,请换一种方式提问」 |
| 成就解锁失败 | 记录错误日志,不影响游戏进行 |

## 5. 验收标准

1. 进入游戏主界面,查看首页醒目位置的玩法说明,确认包含时间限制和失败条件说明
2. 点击「成就系统」进入成就界面,确认成就按五大类分类,每个成就显示名称、图标、描述、解锁条件、完成进度、奖励内容
3. 点击「开始游戏」进入第一关,观察顶部信息栏显示剩余时间「04:30」
4. 在游戏中建设建筑,观察建筑效果数值已中幅下调,财政收入增长速度降低
5. 等待触发紧急事件,确认第一次事件不早于60秒、两次事件至少间隔90秒,且事件弹窗暂停主计时
6. 观察剩余时间少于总时长一半时,时间显示为黄色;少于2分钟时,时间显示为红色并闪烁;少于1分钟时,屏幕边缘出现红色警告框
7. 故意让任意指数归零,确认游戏立即结束,进入失败结算页面,显示具体失败原因
8. 故意超出时间限制,确认游戏立即结束,进入失败结算页面,显示「超出时间限制」
9. 完成第一关目标,进入胜利结算页面,确认显示本局解锁的成就
10. 达成成就条件,确认屏幕中央弹出成就解锁提示,显示成就名称、图标、描述、奖励内容
11. 依次完成第二关至第六关,确认每个关卡时间限制递增,难度逐步提升
12. 完成所有六个关卡,确认解锁「全关卡通关」成就,奖励解锁自由模式
