# 《星光市长》发布验收清单

版本日期：2026-09-01

## 课堂要求与实现证据

| 要求 | 当前实现 | 验收证据 |
|---|---|---|
| 达成条件后能进入下一关 | 通关后进入独立结算状态，由玩家确认继续；下一关序号、目标、计时和地图同步重置 | `tests/gameStore.test.ts` 覆盖第一关结算、进入第二关及最终胜利 |
| 关卡约 5 分钟且更有挑战 | 六关分别为 4:30、4:45、5:00、5:15、5:30、6:00；提高星空、环境、财政及建筑目标 | `tests/gameRules.test.ts` 校验全部时间、目标与每关可行路线 |
| 紧急政策不能过快 | 第一次不早于第 3 天（60 秒），事件间隔至少 3 天（90 秒），滚动 7 天最多 2 次 | `tests/eventRules.test.ts` 覆盖 9 个边界条件 |
| 事件期间给玩家思考时间 | 打开紧急事件、成就、设置或结算弹窗时暂停主倒计时，关闭后恢复 | 状态层暂停/恢复逻辑与浏览器试玩 |
| 修复失败与重试流程 | 超时或指标归零进入失败页，可重试当前关卡 | `tests/gameStore.test.ts` 覆盖暂停、超时与重试相关状态 |
| 精致 3D 建模 | 15 类建筑采用独立轮廓；医院、体育馆、地铁站、商业楼、消防站等新增入口、窗框、屋顶设备、灯架与夜景材质 | 正式构建与桌面浏览器画面验收 |
| 3D 性能 | 动态像素比、性能监控、低端设备自动降级；高质量模式才启用后期效果 | 桌面高画质运行正常，生产构建通过 |
| 多套音效 | 4 套声音方案，覆盖通关、最终通关、失败、成就；含 8 个 MP3 版本与原创浏览器合成方案 | `tests/audioThemes.test.ts` 与声音方案试听面板 |
| 试玩反馈 | 游戏内提供匿名反馈表单；联网时写入 Supabase，未配置时安全保存在本机 | 远端表启用 RLS，仅允许受校验的匿名插入 |
| 可发布 | 使用相对资源路径，可直接用于静态站点；仓库含 GitHub Pages 自动发布流程 | `pnpm check` 完成类型检查、54 项规则检查和正式构建 |

## 发布前人工检查

- [ ] 用一台电脑和一台手机各完成至少一局。
- [ ] 请 3–5 位同学分别试玩并提交反馈，不代填、不虚构结果。
- [ ] 试听通关、失败和成就音效，确认响度一致且没有突然过响。
- [ ] 确认发布环境已填写 Supabase 的项目地址和 publishable/anon key；绝不放入 service-role key。
- [ ] 发布后从公开链接完成一次反馈提交，并在 Supabase 后台确认新增一条记录。

## 自动验收命令

```bash
pnpm check
```
